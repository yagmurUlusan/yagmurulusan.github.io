Selected projects


Agent · tool-calling network
Agentic AI MCP

Agent-Based Task-Oriented Dialogue System

Group project under the INZVA community: a modular, agent-based dialogue system using the Model Context Protocol to connect LLMs with external tools and APIs, with dynamic context injection at inference time for access to up-to-date documents, databases, and services. Code on GitHub.

Factor signals · backtest
Quant Finance R

Factor Investing

Group project on factor investing strategies in R: constructed and evaluated factor-mimicking portfolios, computed factor signals, returns, and information coefficients, and assessed performance through backtesting and risk-adjusted metrics. Code on Google Drive.

Sentiment score trend
NLP FinBERT

Sentiment Analysis for Stock Trading

Implemented multiple sentiment analysis approaches for stock trading signals using web-scraped financial data — training binary classifiers, fine-tuning FinBERT, and building a Llama3-based UI — to compare traditional and advanced NLP models in finance. Code & report on Google Drive.

Literature review · presentation
Generative AI Research

DRP: Directed Reading Program

Research on generative AI under the supervision of Ozan Evkaya (University of Edinburgh), exploring advanced text- and image-generation techniques. Developed and delivered a technical presentation at a symposium after two months of work. Presentation recording on YouTube.
